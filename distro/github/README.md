# Skill-Distributor

> 你来创作 Skill，分发交给 Skill-Distributor

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/op7418/skill-distributor)
[![Platform](https://img.shields.io/badge/platform-WorkBuddy%20%7C%20ClawHub-green.svg)](https://clawhub.ai/skills/skill-distributor)

## 🎯 是什么

Skill-Distributor 是一款 AI 技能分发工具，可以将你的 Skill **一键分发到 10+ 平台**，包括：

- **技能市场**：GitHub / ClawHub / CocoLoop / SkillHub / SkillsBook / 虾技市场
- **社交推广**：小红书 / 即刻 / 知乎 / 掘金

## ✨ 核心价值

| 指标 | 传统方式 | 使用 Skill-Distributor |
|------|----------|----------------------|
| 耗时 | 2 小时+ | **5 分钟** |
| 平台 | 逐个适配 | **一键生成** |
| 格式 | 人工检查 | **自动校验** |

**效率提升 95%+**

## 🚀 快速开始

### 输入

```markdown
帮我分发这个 Skill：/path/to/your-skill/
GitHub 用户名：yourusername
```

### 输出一键生成

```
distro/
├── github/README.md           ← GitHub 仓库
├── platforms/
│   ├── cocoloop.md           ← CocoLoop 上架
│   ├── skillhub-tencent.md   ← SkillHub 上架
│   ├── skillsbook.md         ← SkillsBook 上架
│   ├── xiajimarket.md        ← 虾技市场上架
│   └── clawhub-publish.md    ← ClawHub 发布
├── social/
│   ├── xiaohongshu.md        ← 小红书
│   ├── jike.md               ← 即刻
│   ├── zhihu.md              ← 知乎
│   └── juejin.md             ← 掘金
└── README.md                   ← 分发说明
```

## 🔧 功能特性

- ✅ **智能校验** - 发布前自动检测 SKILL.md 字段完整性
- ✅ **平台兼容** - 自动识别各平台字段差异，屏蔽不兼容参数
- ✅ **品牌统一** - 全平台文案标准化，统一人设与风格
- ✅ **GitHub 推送** - 可选自动推送到 GitHub

## 📦 安装

在 WorkBuddy / ClawHub 中直接搜索安装，或下载 ZIP 后手动安装。
